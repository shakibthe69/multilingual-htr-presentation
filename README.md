# Multilingual Handwritten Text Recognition System (HTR)

An attractive, modern, research-style university project presentation and baseline code structure for recognizing Bangla, English, Digits & Symbols from handwritten images.

## Features

- **Multilingual Support**: Bangla, English (uppercase/lowercase), digits (English/Bengali), and common special symbols.
- **Modern Research Slide Deck**: Built with pure HTML/CSS/JS with smooth animations, grid layouts, timeline nodes, and a modern academic navy/cyan/purple theme.
- **PowerPoint Slide Deck**: Generated programmatically using Python for offline presentations.

---

## Presentation Slides Structure

1. **Title Slide**: Project metadata & visual pipeline sample transformation.
2. **Problem & Motivation**: Messy handwriting script challenges vs. task-specific systems.
3. **Objectives & Scope**: Scope definitions for Bangla, English, Digits, and Symbols.
4. **Literature Review**: Traditional HTR vs. Transformer OCR vs. GraDeT-HTR (2025).
5. **Proposed Approach**: Comprehensive horizontal recognition pipeline layout.
6. **Data & Technology**: Data source listings and tech stack details.
7. **Deliverables & Evaluation**: Metrics benchmarking dashboard.
8. **Use of AI Assistants**: Academic integrity and workflow loop description.
9. **Vision (Final Slide)**: Project synthesis and closing page.

## How to Host Locally

To run the interactive web-based slides presentation locally:

### Option 1: Python HTTP Server (Recommended)
If you have Python installed, open your terminal/command prompt in this project folder and run:
```bash
python -m http.server 8000
```
Then open your browser and navigate to:
```
http://localhost:8000
```

### Option 2: Live Server (VS Code Extension)
1. Open this directory in **VS Code**.
2. Install the **Live Server** extension (by Ritwick Dey).
3. Click the **"Go Live"** button in the bottom-right status bar.
